## 2026-03-31 - Fast AST Function Indexing via Statement Container Filtering
**Learning:** `ast.walk(tree)` traverses every node including expression nodes (`Name`, `Constant`, `Attribute`, `Call`), which comprise over 85-90% of AST nodes in Python modules. When indexing function definitions in `aisec.reach`, walking expression nodes is redundant because functions can only be defined within statement containers (`Module`, `ClassDef`, `FunctionDef`, `If`, `For`, `While`, `With`, `Try`, etc.). Traversing only statement containers speeds up function indexing by ~7x and reduces overall reachability assessment time by ~41%. Reusing `list(ast.walk(fn))` once per function avoids 6x redundant re-walks of the same subtree during propagation, guard detection, and sink checks.
**Action:** Always filter child nodes to statement containers when searching for function/class definitions in Python ASTs, and cache subtree nodes when performing multi-pass analysis on function bodies.
